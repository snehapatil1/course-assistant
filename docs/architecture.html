Hybrid RAG

  • • Keyword (BM25) + text embeddings + visual embeddings
  • • Text and visual indexes kept separate, fused at query time
  • • RRF fusion → multimodal rerank → best evidence

Q&A & Quiz

  • • Structured output: {answer, sources} — validated
  • • Missing info acknowledged; answers never invented
  • • Quizzes: MCQs from chosen material + topic filter
  • • Fixed answer key (hidden), scores, cited explanations

Security & transparency

  • • Keys only in local .env; dummy values in docs/examples
  • • Never in UI, logs, errors, screenshots, or GitHub
  • • Sources support every answer (excerpt or page image)
  • • Repeatable tests + PROGRESS.md log of what is verified
